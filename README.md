# Product Catalog — Organic Products

A responsive product catalog for organic produce with a search filter and modal previews.

**Stack:** HTML, CSS, JavaScript
**Live:** https://prodnrqz.vercel.app/

## Features

- Responsive product grid (CSS grid, auto-fit)
- Search bar — type to filter products by name
- Click any product for a modal preview with rating, description, and price
- Buy Now / Add to Cart buttons in the preview

Demonstrates: CSS grid layout, responsive design, product card UI, vanilla JS filtering and modals.
